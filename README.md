# Music Player

Un reproductor de música construido con tecnologías web básicas (HTML, CSS y JavaScript Vanilla). Mayo 2025

## Características

- Reproducción de pistas de audio (archivos locales).
- Visualización de la portada, título y artista de la canción.
- Interfaz responsiva gracias al uso de **CSS Grid** y **Media Queries**.
- Controles de reproducción interactivos: anterior, siguiente, pausa/reproducir.
- Modos de reproducción (aleatorio, repetición y en bucle).
- Actualización en tiempo real del tiempo de reproducción.

## Estructura del Proyecto

- `index.html`: Punto de entrada a la aplicación.
- `style/index.css`: Hoja de estilos principal
- `script/index.js`: Lógica principal del reproductor
- `bucket/`: Contiene los recursos visuales y las portadas de música (`Portadas/`) además de iconos SVG (`icon/`).

## Instalación y Uso

1. Clona o descarga este repositorio en tu ordenador.
2. Abre el archivo `index.html` directamente en tu navegador web.
3. Al hacer clic en el botón de "Play" empezará a sonar tu lista de reproducción configurada.
